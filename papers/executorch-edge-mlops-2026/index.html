Edge MLOps: Building a Pipeline from PyTorch Training to On-Device Inference with ExecuTorch

RanjithKumar Ragavan

Independent Technical Report (Expanded from Conf42 Talk) · TR-2026-02 · 2026/11/05

Download Full Paper (PDF) Conf42 Speaker Page ↗

Abstract

Cloud-centric MLOps pipelines stop at server endpoints and overlook mobile constraints such as RAM ceilings, thermal throttling, battery budgets, and heterogeneous hardware fleets. Drawing on practical contributions to Meta's PyTorch ExecuTorch runtime, this technical report outlines a reproducible edge MLOps pipeline covering model export, quantization, mobile runtime packaging, and on-device telemetry.
